#  CGPA Calculator & Student Record Management System

A C++ console-based application that calculates SGPA/CGPA and manages student academic records using Object-Oriented Programming and File Handling.

---

##  Features

* Enter student details (Name and Roll Number)
* Add multiple courses with grades and credits
* Calculate SGPA/CGPA automatically
* Calculate percentage equivalent
* View detailed course report
* Save student reports to files
* Search student reports using Roll Number
* View all registered students
* Input validation for a smooth user experience

---

##  Technologies Used

* C++
* Object-Oriented Programming (OOP)
* STL Vector
* File Handling
* Modular Programming
